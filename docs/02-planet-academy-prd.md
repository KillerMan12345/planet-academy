# 星球学院 · 产品设计文档 PRD v1.0

> **Planet Academy** — 让每个孩子拥有一座属于自己的学习星球  
> 面向 5~10 岁儿童 · 五大学院 · 开源生态集成 · 离线优先 · 零广告零内购

---

## 壹 · 产品愿景

### 核心定位

> **"将世界最好的开源教育工具，整合成一款中国孩子能用的综合学习宇宙"**

星球学院不是一款学科 App，而是一个**儿童学习生态**：五大知识学院各自独立，又通过共同的成长货币、宠物伴侣和星球地图形成有机联动。孩子在这里不是"完成作业"，而是**探索一个等待被发现的星球**。

### 产品价值三角

```
        🌟 有趣
       /        \
      /          \
 🧠 有效 ——— 🛡️ 安全
```

- **有趣**：每个学习行为都包裹在游戏化机制中，学习即游戏
- **有效**：所有课程设计基于已验证的教育科学（CPA / Phonics / SM-2 间隔复现）
- **安全**：儿童端零广告、零内购、零数据上传，家长功能密码隔离

---

## 贰 · 目标用户

### 主用户：5~10 岁儿童（三个亚群）

| 年龄段 | 称号 | 能力特点 | 主要学院 |
|:---|:---|:---|:---|
| **5~6 岁** | 小星探 | 识字有限，以听觉/图像为主，注意力 10~15 分钟 | 语言启蒙、音乐美育 |
| **7~8 岁** | 星球学者 | 能独立阅读，开始逻辑思维，注意力 20 分钟 | 数理逻辑、科学探究 |
| **9~10 岁** | 宇宙探险家 | 可完成多步任务，有创作欲，注意力 30 分钟 | 少儿编程、跨学科创作 |

### 次用户：家长 / 监护人
- 希望了解孩子学习进度，但不干预学习过程
- 需要设置学习时长上限和学科偏好
- 不希望孩子在 App 内接触任何商业内容

### 🌟 学院 I · 语言阅读学院

```

│   │   ├── 音素感知小游戏（怪兽吃字母 ← Feed The Monster 设计）

│   ├── 第二港 · 拼读湾（Phonics）

│   │   ├── 常见双字母组合（sh/ch/th/wh）
│   │   └── 二级音素混合拼读
│   └── 第三港 · 阅读海（Reading）
│       ├── Sight Words 见词识义（Dolch 220词）
│       ├── 分级绘本（L1/L2/L3 ← StoryWeaver 内容）
│       └── 听读理解互动故事

├── 🀄 汉字大陆
│   ├── 第一城 · 象形城（象形字 50个）
│   │   ├── 字理演化动画（甲骨文→金文→楷书）
│   │   ├── 田字格笔顺描红（手指绘制）
│   │   └── 象形配对游戏
│   ├── 第二城 · 笔顺镇（218常用生字）
│   │   ├── 分类字库（自然/身体/动物/数字/颜色 8类）
│   │   ├── 笔顺演示与跟练
│   │   └── 组词造句练习
│   └── 第三城 · 词语森林
│       ├── 近义词/反义词配对

│   │   ├── 静夜思/春晓/悯农/登鹳雀楼等

└── 🔤 拼音乐园
    ├── 声母23个 + 韵母24个 认读

## 伍 · 成长与激励系统

### 核心货币：✨ 星光值

- 首次解锁新知识：+30 星光（探索奖励）
- 连续打卡 7 天：+100 星光
- **绝不因答错扣星光**（零惩罚原则）

### 成长系统：🪐 我的星球

```
星球进化轨迹：
🌑 陨石 → 🟤 泥土球 → 🌍 绿洲星 → 🌟 文明星 → 🌌 传奇星球

### 宠物系统：🦁 学习小伙伴

- 初始赠送一个小伙伴（5种可选：小狮子/小猫头鹰/小兔子/小海豚/小狐狸）

- 宠物有语音鼓励台词，每次正确答题随机触发一句

### 儿童 UI 核心规范

1. **触控热区**：所有可点击元素 ≥ 88px × 88px
2. **字体大小**：正文 ≥ 16px，标题 ≥ 20px，圆润无衬线字体
3. **颜色**：明快柔和，无荧光刺眼色，通过 AA 级色彩对比度

## 柒 · 技术架构

### 技术选型原则

- **纯 Web 技术栈**（HTML5 / CSS3 / Vanilla JS）— 无重型框架，便于离线
- **Capacitor 打包**Android / iOS 原生 App
- **离线优先**— 核心功能 100% 本地运行，内容包可选下载

### 开源集成技术方案

| 开源项目 | 集成方式 | 技术细节 |
|:---|:---|:---|
| **Google Blockly** | 直接引入 JS 库 | `<script src="blockly.min.js">` + 自定义工具箱 |
| **Chrome Music Lab** | iframe 嵌入 | `<iframe src="https://musiclab.chromeexperiments.com/Song-Maker/song/...">` |
| **PhET Simulations** | iframe 嵌入 + 本地缓存 | 本地存储 .html 文件，避免网络依赖 |
| **Scratch 项目** | iframe 嵌入 / scratch-vm | 精选项目本地化存储 |
| **Music Blocks** | iframe 嵌入 | 嵌入 musicblocks.sugarlabs.org |
| **StoryWeaver 内容** | 内容数据转换 | 将 CC BY 4.0 绘本转为本地 JSON + 图片 |
